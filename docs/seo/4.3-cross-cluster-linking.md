# Inter-Cluster Semantic Linking Strategy

While clusters (Home, Car, Personal) run vertically, we must build a horizontal semantic web to signal broader financial authority to Google.

## The Strategy

### 1. Home Loan to Personal Loan Bridge
**Context:** People buying homes often need extra funds for interior design or down payment shortfalls.
**Link Source:** `/home-loan-calculator` (Hub or Guide section)
**Link Target:** `/personal-loan-calculator`
**Anchor Text:** "...cover interior furnishing costs with a short-term [personal loan]."

### 2. Car Loan to Personal Loan Bridge
**Context:** Evaluating if a used car loan or a personal loan has better rates.
**Link Source:** `/car-loan-calculator/used-car-emi-calculator`
**Link Target:** `/personal-loan-calculator`
**Anchor Text:** "...compare these rates against a standard [personal loan] to see which is cheaper."

### 3. Personal Loan to Home Loan Bridge
**Context:** Top-up loans.
**Link Source:** `/personal-loan-calculator`
**Link Target:** `/home-loan-calculator`
**Anchor Text:** "...if you already have an existing mortgage, a [home loan top-up] might offer lower rates than a personal loan."

## Implementation Risk
**Dilution:** Linking to unrelated clusters (e.g., if we added a "PDF Tools" cluster to our "Finance" site) destroys topical authority.
**Mitigation:** Only link across clusters where user intent naturally overlaps.
