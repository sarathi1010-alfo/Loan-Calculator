# Weekly SEO Review Framework

This SOP guarantees our programmatic SEO architecture is responding correctly to search demand.

## Required Tools
- Google Search Console (GSC)
- Google Analytics 4 (GA4)

## The 5-Step Weekly Review

### 1. Breakout Tools
- **Filter:** GSC > Performance > Compare last 7 days to previous 7 days. Sort by Clicks Difference (High to Low).
- **Action:** If a specific tool (e.g., `50-lakh-sbi-home-loan`) is breaking out, instantly generate 5-10 adjacent tools (`40-lakh`, `60-lakh`) via the ontology generator to capture the cluster.

### 2. Opportunity Queue (High Impr. / Low CTR)
- **Filter:** GSC > Performance > Impressions > 100, CTR < 2%.
- **Action:** These tools are ranking on page 1/2 but look unappealing. Rewrite the `generateSemanticBlocks` logic for this specific cluster to output a punchier `<title>` and meta description.

### 3. Latent Rankers (High Impr. / Position 20+)
- **Filter:** GSC > Performance > Position > 20, Impressions > 500.
- **Action:** These tools have search volume but lack authority. Point internal links from the Hub page directly to these specific URLs.

### 4. Intent Mismatch (Zero Clicks)
- **Filter:** GA4 > Pages and screens > Sort by Views (High to Low) > Filter for 0 Engagement Time.
- **Action:** Users are landing but instantly bouncing. Ensure the calculator auto-populates the exact values requested in the URL slug so the user doesn't have to type anything.

### 5. Keyword Expansion
- **Filter:** GSC > Queries > Filter for queries *not containing* "calculator" or "emi".
- **Action:** Add these modifiers to the ontology generator. (e.g., If users search "interest rate", build an Interest Rate comparison variant).
