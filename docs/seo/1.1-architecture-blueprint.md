# Programmatic SEO Architecture Blueprint

## Overview
This architecture scales an AI micro-tool ecosystem (Loan Calculators) to 1,000+ indexed pages. The project is built on Next.js App Router and deployed on Vercel.

## Folder & File Structure

```text
/src
  /app
    layout.tsx               # Global root layout (NavBar, Footer, Providers)
    page.tsx                 # Root landing page (Hub)
    sitemap.xml              # Dynamic Sitemap Index Generator
    /robots.txt              # robots.txt Generator route
    /[cluster]               # e.g., /home-loan-calculator
      page.tsx               # Cluster Hub Page
      /[tool-name]           # e.g., /50-lakh-sbi-home-loan-emi-for-10-years
        page.tsx             # Dynamic Tool Spoke Page (SSR/ISR)
  /components
    /seo
      StructuredData.tsx     # JSON-LD Schema Injector
      Breadcrumbs.tsx        # Dynamic Breadcrumb Navigation
    /calculators
      EmiCalculator.tsx      # Deterministic UI Component
  /lib
    seo-metadata.ts          # Automated Metadata Generation Pipeline
/scripts
  generate-seo-entities.ts   # Ontology Generator for pSEO
  submit-sitemap.ts          # GSC API Sitemap Submitter
/data
  /generated
    seo-pages.json           # Machine-readable ontology output
```

## URL Strategy
- Flat structure: `/[cluster]/[tool-slug]`
- No nesting deeper than 2 levels past the root.
- All pages link to their respective hub and 2-3 sibling nodes.

## Rendering System
- Hub pages use SSG (`generateStaticParams`).
- Spoke pages use SSR or ISR based on velocity requirements, heavily utilizing Vercel's Data Cache.

## Automated sitemap.xml Logic (Pseudocode)

```typescript
export async function GET() {
  const clusters = ['home-loan-calculator', 'car-loan-calculator', 'personal-loan-calculator'];
  const indexXml = buildSitemapIndex(clusters.map(c => `https://domain.com/sitemap-${c}.xml`));
  return new Response(indexXml, { headers: { 'Content-Type': 'text/xml' }});
}
```

## Automated Schema (TypeScript)

```typescript
export function generateSoftwareApplicationSchema(tool: GeneratedEntity) {
  return {
    "@context": "https://schema.org",
    "@type": "SoftwareApplication",
    "name": tool.title,
    "operatingSystem": "All",
    "applicationCategory": "FinanceApplication",
    "offers": {
      "@type": "Offer",
      "price": "0",
      "priceCurrency": "INR"
    }
  };
}
```

## Canonical Tag Pattern
Inserted globally via `metadataBase` and `alternates.canonical` in `generateMetadata()`.

## Robots.txt Template

```text
User-agent: *
Allow: /

# Block unnecessary crawling
Disallow: /api/
Disallow: /_next/
Disallow: /admin/
Disallow: /*?*

Sitemap: https://yourdomain.com/sitemap.xml
```
