# EEAT Signal Audit for Utility Tools

For a programmatic micro-tool site, Google's Quality Raters look for specific trust signals to ensure the calculator isn't just thin, scraped content.

## Page-Level EEAT Checklist

1. [ ] **Methodology Statement:** Does the page briefly explain the math behind the calculation? (e.g., "Calculated using the standard reducing balance method.")
2. [ ] **Accuracy Disclaimer:** Is there a note stating "Actual rates may vary based on bank policies and CIBIL score"? (Crucial for YMYL finance pages).
3. [ ] **Visual Proof:** Are the results presented professionally? (e.g., Using Recharts for an amortization pie chart vs. just printing text).
4. [ ] **Freshness Timestamp:** Is there a "Rates updated as of [Month Year]" tag?
5. [ ] **No Ads Above Fold:** Is the primary utility (the calculator) immediately usable without scrolling past AdSense banners?

## Site-Level EEAT Checklist

1. [ ] **Clear "About Us" / Mission:** Explaining _why_ this tool ecosystem exists (e.g., "To make financial planning transparent").
2. [ ] **Privacy Policy / Terms:** Crucial for finance sites.
3. [ ] **HTTPS / Security:** Enforced by Vercel by default.
4. [ ] **No Broken Math:** The deterministic function must be unit-tested. If `1+1=3`, Google will detect poor user signals (instant bounce) and rank it down.
5. [ ] **Contact Information:** A way for users to report bugs or suggest features.
