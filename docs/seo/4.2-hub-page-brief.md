# Hub Page Brief

**Target URL:** `/home-loan-calculator`
**Primary Keyword:** Home Loan EMI Calculator
**Secondary Keywords:** Housing loan calculator, EMI calculator for home loan, check home loan EMI, housing finance calculator

## Search Intent Analysis

The user wants to instantly know their monthly financial commitment. They don't want to read a wall of text _first_. The tool must be above the fold. Secondary intent is understanding _how_ the interest is calculated and how to save money.

## Recommended Page Structure

1. **H1:** Home Loan EMI Calculator (Instant & Accurate)
2. **[Interactive Component]:** The Master `EmiCalculator.tsx` (fully configurable).
3. **H2:** How is Home Loan EMI Calculated?
   - Explain the formula: `E = P x r x (1+r)^n / ((1+r)^n - 1)`
4. **H2:** Current Home Loan Interest Rates (2024)
   - Data table linking to Level 1 Spokes (SBI, HDFC, ICICI).
5. **H2:** How to Reduce Your Home Loan EMI
   - Link out to informational guides.
6. **H2:** Frequently Asked Questions (FAQ)
   - 5 manually written, highly-optimized questions.

## JSON-LD Schema

Must inject an array of schemas:

1. `WebPage`
2. `SoftwareApplication` (For the calculator itself)
3. `FAQPage` (For the QA section)
