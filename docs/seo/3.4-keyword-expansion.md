# Keyword Expansion Loop (Based on Loan Tools)

This framework takes actual search behavior and turns it into new programmatic entities.

## Step 1: Harvest GSC Query Data

Assume GSC shows high impressions (Position 15-30) for these queries that we _don't_ have exact pages for:

- "hdfc home loan preclosure calculator"
- "sbi maxgain home loan calculator"
- "car loan emi calculator with prepayment"
- "home loan interest subsidy calculator"

## Step 2: Systematize the Variations

Instead of building 4 random pages, we integrate these modifiers into the ontology system.

### New System Modifiers

- `feature`: "preclosure", "maxgain", "prepayment", "subsidy"

## Step 3: Expand the URL Architecture

Generate these new URL patterns:

- `/home-loan-calculator/hdfc-preclosure-calculator`
- `/home-loan-calculator/sbi-maxgain-emi-calculator`
- `/car-loan-calculator/emi-with-prepayment`

## Step 4: Component Expansion

To support these pages, the `EmiCalculator.tsx` component needs new props:

- `allowPrepayment: boolean`
- `isOverdraftFacility: boolean` (for Maxgain)

## Step 5: Prioritization Matrix

| Cluster   | New Idea                        | Priority Score         | URL Slug                                             |
| :-------- | :------------------------------ | :--------------------- | :--------------------------------------------------- |
| Home Loan | Preclosure / Prepayment Variant | **HIGH** (High intent) | `/home-loan-calculator/[bank]-prepayment-calculator` |
| Car Loan  | Prepayment Variant              | **MED**                | `/car-loan-calculator/[bank]-prepayment-calculator`  |
| Home Loan | Subsidy (PMAY) Calculator       | **HIGH**               | `/home-loan-calculator/pmay-subsidy-calculator`      |

## Step 6: Execute

Update `scripts/generate-seo-entities.ts` to include these new arrays and logic loops, run the script, and deploy. We instantly go from 1,000 pages to 1,500 highly-targeted pages.
