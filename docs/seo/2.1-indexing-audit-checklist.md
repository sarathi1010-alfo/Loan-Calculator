# Indexing Audit Checklist

Before considering a new batch of micro-tool pages "done," run this audit to prevent indexation bloat or crawl failure.

| Check                        | How to Test                                           | Pass Criteria                                                                  | What to Fix If Failing                                                                           |
| :--------------------------- | :---------------------------------------------------- | :----------------------------------------------------------------------------- | :----------------------------------------------------------------------------------------------- |
| **Noindex Tag Check**        | `curl -s URL \| grep -i "noindex"`                    | Empty result (no tag exists)                                                   | Remove `<meta name="robots" content="noindex">` injected by misconfigured metadata layouts.      |
| **JS Rendering Block**       | View page source (Ctrl+U), search for core UI text.   | The core text and calculator output (or inputs) exist in the raw HTML payload. | Switch component from CSR to SSR/SSG. Ensure `next/dynamic` isn't wrapping the entire page.      |
| **Canonical Alignment**      | `curl -s URL \| grep -i "canonical"`                  | URL matches exactly what is in the browser bar.                                | Fix `metadataBase` and `alternates.canonical` logic in Next.js `generateMetadata`.               |
| **Server Response Time**     | DevTools -> Network -> Doc -> TTFB                    | TTFB < 800ms.                                                                  | Utilize Next.js Data Cache (ISR), remove synchronous DB/API calls from `page.tsx`.               |
| **Internal Link Graph**      | Screaming Frog crawl or manual check of the Hub page. | The page is reachable within 3 clicks from the homepage.                       | Add the page to the `seo-pages.json` ontology graph; ensure sibling link component is rendering. |
| **Duplicate Content/Params** | Add `?utm=test` to the URL                            | The canonical tag still points to the clean, parameter-less URL.               | If it changes to the dirty URL, hardcode the canonical route.                                    |
