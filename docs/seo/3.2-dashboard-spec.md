# GSC + GA4 Integration Dashboard Spec

A custom dashboard built (e.g., in Looker Studio) to unify our execution logic.

## Data Sources
1. **GSC Connector:** Impressions, Clicks, CTR, Position (URL-level)
2. **GA4 Connector:** Organic Sessions, Engagement Time, Custom Events (`calculator_used`, `pdf_downloaded`)

## Dashboard Views

### View 1: The "Breakout" Matrix (Top Left)
- **Visualization:** Scatter plot
- **X-axis:** Impressions (GSC)
- **Y-axis:** Engagement Time (GA4)
- **Insight:** Pages in the top right are our "Golden Geese". We must protect their rankings at all costs by ensuring zero server errors and fast TTFB.

### View 2: The "Bleeding" Queue (Bottom Left)
- **Visualization:** Bar chart (red)
- **Data:** URLs losing >20% clicks month-over-month.
- **Action:** Re-run the generation script to refresh the `lastmod` date in the sitemap and slightly tweak the `intro` paragraph for freshness.

### View 3: Conversion Heatmap (Right)
- **Visualization:** Table with heat-mapping
- **Columns:** Page Path | Organic Traffic | `calculator_used` Event Count | Conversion Rate
- **Insight:** If a tool page has 5,000 visits but only 10 calculator executions, the UX is broken or the page layout is pushing the tool below the fold.

### View 4: Cluster Authority Monitor
- **Visualization:** Line graph (stacked)
- **Data:** Total clicks segmented by URL prefix (`/home-loan-calculator/` vs `/car-loan-calculator/`).
- **Insight:** Tells us which vertical Google trusts us most for, dictating where we should expand our ontology next.
