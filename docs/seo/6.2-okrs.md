# SEO Roadmaps: Phases 2-4 OKRs

## Phase 2 (Months 4-6): Cluster Expansion
**Objective:** Broaden horizontal topical authority by launching Car and Personal Loan clusters.
- **KR 1:** Deploy `/car-loan-calculator` and `/personal-loan-calculator` Hubs.
- **KR 2:** Generate and index 300 new valid tool permutations.
- **KR 3:** Establish inter-cluster linking (e.g., Car -> Personal).
- **Anti-Goal:** Do not worry about backlink outreach; focus purely on structural on-page signals.

## Phase 3 (Months 7-9): Authority & EEAT Building
**Objective:** Protect rankings from core updates by solidifying trust signals.
- **KR 1:** Publish 15 deep, manually written supporting guides attached to the Hub pages.
- **KR 2:** Implement global EEAT methodology disclaimers on all 400+ tool pages.
- **KR 3:** Achieve a < 30% bounce rate on tool pages by improving input UI.

## Phase 4 (Months 10-12): AI Search & Dominance
**Objective:** Optimize specifically for ChatGPT, Gemini, and Google AI Overviews.
- **KR 1:** Ensure 100% FAQPage schema compliance across all tool pages.
- **KR 2:** Format all H2s as explicit questions and the immediate text block as a succinct 50-word answer.
- **KR 3:** Reach 1,000 indexed pages with < 5% pruning rate.
- **Anti-Goal:** Heavy monetization (AdSense) that ruins UX and hurts AI citation probability.
