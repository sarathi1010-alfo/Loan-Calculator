# Component-Driven Tool Template System

To scale to 1,000+ pages efficiently, we cannot build bespoke pages. We build a finite set of UI templates that accept configuration payloads.

## The Core Template: EmiCalculator

**File:** `src/components/calculators/EmiCalculator.tsx`
**Role:** Pure, deterministic UI component.

### Props Interface

```typescript
interface EmiCalculatorProps {
  initialAmount?: number;
  initialTenure?: number; // In months
  initialRate?: number;
  bankName?: string;
  loanType?: "home" | "car" | "personal";
  hideBankSelector?: boolean; // True for programmatic spoke pages
}
```

### Layout Flow

1. **Header:** Dynamic Title (e.g., "{bankName} {loanType} Calculator").
2. **Inputs:** Sliders for Amount, Tenure, Rate. (Auto-filled by props).
3. **Primary Output:** Giant typography showing the exact monthly EMI (₹).
4. **Secondary Output:** Recharts Pie Chart (Principal vs Interest).
5. **Tertiary Output:** HTML Table (Amortization Schedule).
6. **Action:** "Download PDF Report" (Uses jsPDF/html2canvas).

### The Reusability Magic

By passing `initialAmount=5000000`, `initialTenure=120`, `initialRate=8.5` to this component inside `[slug]/page.tsx`, the tool instantly renders exactly what the user searched for without any client-side interaction required.

## Additional Archetypes

If we expand beyond EMIs, we need templates for:

- **Checker/Validator:** e.g., "CIBIL Score Checker" (Input: Data -> Output: Pass/Fail UI).
- **Generator:** e.g., "Amortization Schedule Generator" (Input: Data -> Output: Exportable Table/PDF).
