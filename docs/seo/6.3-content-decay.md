# Content Decay Prevention System

Programmatic pages can decay if search engines detect they haven't changed in months.

## Decay Detection Workflow
1. **Metric:** Month-over-Month Impressions (from GSC).
2. **Threshold:** If a cluster drops > 15% in impressions MoM, it is decaying.

## Freshness Injection Tactics
Since we can't manually edit 1,000 pages, we inject freshness programmatically:

### Tactic 1: Dynamic Rate Updates
If the RBI changes repo rates, update the generic fallback rates in `scripts/generate-seo-entities.ts`.
```typescript
const BANKS = [
  // Was 8.5, updated to 8.7 in October 2024
  { id: 'generic', name: '', rateHome: 8.7, rateCar: 9.0, ratePersonal: 11.5 },
];
```
*Impact: This forces a new calculation for all generated URLs and updates the timestamp on the sitemap.*

### Tactic 2: Rotating FAQ Context
Update the deterministic text blocks to reference the current year or recent financial changes.
```typescript
const intro = `Planning to take a ${bankStr}${loanTypeStr} of ${amountStr} in 2024? ...`;
```

## Maintenance Schedule
- **Quarterly:** Review and update interest rate baselines in the generator script. Run the script to touch all files.
- **Bi-Annually:** Rewrite the core `intro` and `description` semantic block templates to ensure Googlebot sees entirely new HTML structure during its crawl.
