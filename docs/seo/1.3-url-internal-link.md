# URL & Internal Link Architecture

## Core Rules for PSEO Link Architecture

1. **Subfolders, not Subdomains:** `domain.com/pdf-tools/` not `pdf-tools.domain.com`. This consolidates domain authority.
2. **Flat Hierarchy:** Maximum 3 levels deep (`/cluster/tool-name`).
3. **Hub and Spoke:** Spoke pages link up to Hubs; Hubs link down to top Spokes.
4. **Sibling Linking:** Every spoke links to 2-3 semantically related sibling spokes.

## Breadcrumb Schema Template (JSON-LD)

```typescript
export function generateBreadcrumbSchema(
  clusterName: string,
  clusterSlug: string,
  toolName: string,
  toolSlug: string,
) {
  return {
    "@context": "https://schema.org",
    "@type": "BreadcrumbList",
    itemListElement: [
      {
        "@type": "ListItem",
        position: 1,
        name: "Home",
        item: "https://domain.com",
      },
      {
        "@type": "ListItem",
        position: 2,
        name: clusterName,
        item: `https://domain.com/${clusterSlug}`,
      },
      {
        "@type": "ListItem",
        position: 3,
        name: toolName,
        item: `https://domain.com/${clusterSlug}/${toolSlug}`,
      },
    ],
  };
}
```

## Automated Sibling Internal Linking (TypeScript Logic)

```typescript
interface Entity {
  slug: string;
  cluster: string;
  amount: number;
  tenure: number;
}

export function generateSiblingLinks(
  currentEntity: Entity,
  allEntities: Entity[],
): string[] {
  const relatedSlugs = new Set<string>();

  // 1. Same cluster, same amount, different tenure
  const sameAmount = allEntities.find(
    (e) =>
      e.cluster === currentEntity.cluster &&
      e.amount === currentEntity.amount &&
      e.slug !== currentEntity.slug,
  );
  if (sameAmount) relatedSlugs.add(sameAmount.slug);

  // 2. Same cluster, same tenure, different amount
  const sameTenure = allEntities.find(
    (e) =>
      e.cluster === currentEntity.cluster &&
      e.tenure === currentEntity.tenure &&
      e.slug !== currentEntity.slug,
  );
  if (sameTenure) relatedSlugs.add(sameTenure.slug);

  // Return max 3 related slugs
  return Array.from(relatedSlugs).slice(0, 3);
}
```

## Why Subfolders over Subdomains?

Search engines often treat subdomains (`calculators.domain.com`) as separate entities from the root domain (`domain.com`). By using subfolders (`domain.com/calculators`), all backlinks and historical authority acquired by the root domain instantly flow to the programmatic tool pages, significantly accelerating indexing and ranking velocity.
